# Visitor evaluation tools

This directory holds the collector and scorer for MuseBridge's public Agent
evaluation. The independent visitor questions, review sheets and browser
acceptance record are maintained separately on
[visitor-acceptance](https://github.com/Jasonssssss9/musebridge/tree/visitor-acceptance/acceptance).
The reviewed project inventory identifies its original draft at
[`8da4cbf`](https://github.com/Jasonssssss9/musebridge/tree/8da4cbf/acceptance).
Jeremiah Lim (A) authored that suite with assistance as documented on the source
branch. Keep its raw data outside this checkout and out of development prompts.

The draft preflight checked 240 single-turn variants, 154 language-state transitions
and 185 source references with no structural or metadata issues. The actual
independent visitor, language and source/state approvals are pending. No independent
message was sent during this verification.

See the [evaluation runbook](evaluation-runbook.md) for public development
rehearsal, use of the external reviewed suite and interpretation of the results.

Reviewers can follow the [human review and freeze handoff](evaluation-runbook.md#human-review-and-freeze-handoff) to preserve their signatures and verify the final suite offline.
